# Creation of Tux — живые ASCII-обои

Автор композиции и проекта: **4EL1k**. Нативные обои для Linux/Wayland:
вращение Tux, переливание символов, настоящая сетка ASCII. Без видео и браузера.
**Noctalia не обязательна.**

## Установка

Скачайте ZIP репозитория, распакуйте, установите зависимости из основного README.
В папке проекта выполните:

```sh
python3 install.py
```

Установка в домашнюю папку, без sudo. Откройте **Creation of Tux** в меню
приложений, выберите детализацию, FPS, размер, период вращения, мониторы и
нажмите **Start**. GTK4/PyGObject нужны только для окна настроек.

Без окна настроек:

```sh
~/.local/bin/creation-of-tux start
~/.local/bin/creation-of-tux stop
~/.local/bin/creation-of-tux configure balanced
~/.local/bin/creation-of-tux doctor
```

Для автозапуска включите переключатель в окне настроек. Если композитор не
читает XDG autostart, добавьте `~/.local/bin/creation-of-tux start` в его
автозапуск самостоятельно. Примеры есть в основном README.

Поддерживается Wayland с layer-shell, EGL/GLES2. Проверено на CachyOS/Hyprland.
Sway/niri реализуют нужный протокол, но пока не проверены вживую.
Обычный GNOME, X11 и Windows этим рендерером не поддерживаются.

Старую персональную версию `creation-ascii` и новую версию не запускайте
одновременно: обе используют слой фона.

## Удаление

```sh
python3 ~/.local/share/creation-of-tux/install.py --uninstall
```

Настройки и журнал сохраняются. Чужие обои, бинды и конфигурация оболочки
установщиком не переписываются. Дополнительные сведения, зависимости и
исходные изображения: [README](../README.md), [авторство](../THIRD_PARTY.md).
